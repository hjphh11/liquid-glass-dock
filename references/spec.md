# 规格与原理

## 一、绘制顺序（自下而上）

代码里的顺序就是屏幕上的顺序，任何一层错位都会导致"看着不对但说不上哪不对"。

| # | 层 | 内容 | 关键点 |
|---|---|---|---|
| 1 | 页面内容 | 首页的封面墙 / 列表 | 被录进 `BackdropSource`，作为玻璃的采样纹理 |
| 2 | 药丸玻璃 | blur + 提饱和 + tint + 边缘折射 + 白高光 + 阴影 | 圆角 = 高 ÷ 2，整条一个整体 |
| 3 | 未选中行 | 4 格灰色图标 + 文字，全部绘制 | 位于玻璃**之上**，所以永远清晰 |
| 4 | 指示器 | 一格宽的第二块玻璃 | 自带位移，叠 13% 主题色膜 |
| 5 | 选中行（藏在指示器里） | 4 格实心图标 + 加粗文字 | 只录纹理不直接绘制，由指示器当作锐利层贴出 |

第 5 层的技巧值得单独说明：`TabRowContent(accent = true)` 外面套的是 `hiddenBackdropSource`，它把内容录进一张 GraphicsLayer 但不画在屏幕上。指示器的 `glass(sharpSources = listOf(accentSource))` 再把这张纹理以 `blur = 0` 采样回来，按自己的裁剪区域显示对应的一格。

结果就是：**选中项看起来是玻璃内部的东西，而不是浮在玻璃上**。这也解释了为什么指示器移动时高亮内容会跟着一起走，而不是先消失再出现。

## 二、几何

| 量 | 值 | 说明 |
|---|---|---|
| 条高 | 62dp | 含内距 |
| 内距 | 5dp | 玻璃边缘到内容 |
| 每格宽 | `clamp(64, (屏宽−36)/格数, 92)` | 36 = 两侧留白 2×13 + 内距 2×5 |
| 外圆角 | 31dp | 恒为条高 ÷ 2，胶囊形 |
| 指示器 | 每格宽 × 52dp | 高 = 62 − 5×2 |
| 指示器圆角 | 26dp | 恒为 (高 − 2×内距) ÷ 2 |
| 图标 / 间距 / 字号 | 22dp / 3dp / 11sp | 文字 SemiBold(选中)、Medium(未选) |
| 底部离屏 | 10dp + 导航栏 inset | 有系统导航栏时 inset + 6dp |

窄屏优先保 4 格塞得下，宽屏不让单格超过 92dp 变成空荡的肥条。

## 三、材质

### 药丸（外层）

```
cornerRadius   31dp
blur           5dp          ← 故意小，保留背后封面色
saturation     1.5
tint           深色 #000 / 24%；浅色 #fff / 34%
lens           true
refractionH    24dp
refractionAmt  24dp
dispersion     true         ← 边缘彩边
highlight      #fff / .55（深）或 .8（浅），线宽 0.7dp
shadow         14dp，黑 35%
fallback       主题 surfaceContainerHigh
```

### 指示器

```
cornerRadius   26dp
lens           同外层开关
refractionH    12dp
refractionAmt  16dp
highlight      #fff / .85
shadow         0dp
额外           叠加主题色 13% 的矩形膜，按下时降到 6%
fallback       主题 surfaceContainerHigh（指示器不采样页面，只采样锐利层）
```

关闭液态玻璃（`liquid = false`）时：blur 提到 26dp、tint 换成 surfaceContainerHigh 66~70%、去掉折射与拆色、高光降到 .14，退化成普通毛玻璃条。

## 四、动效

| 场景 | 曲线 |
|---|---|
| 点击切换 | `spring(dampingRatio .72, stiffness 380)` |
| 拖动中 | 直接 `snapTo`，无动画；越界走橡皮筋 `rubberband(x, dim = 格宽×0.4, k = .55)` |
| 松手 | `round((x + projectFling(v, .99)) / 格宽)` 定目标格，`spring(.86, 420)` 带 `initialVelocity` 收尾 |
| 按下 | `press` 0→1，`spring(.85, 600)`；指示器 scale 1.08，横向拉伸按 `|v|/7000` 上限 16% |
| 抬起 | `press` 1→0，`spring(.82, 300)` |
| 触感 | 拖过格中心 tick 一次；点击/落定一次 |

`projectFling(v, rate) = v/1000 × rate/(1−rate)`，即按每秒衰减率折算剩余位移。`rate = .99` 时约等于 `v × 0.099` 秒的惯性距离。

## 五、AGSL 折射在做什么

1. 用圆角矩形的 SDF 求出每个像素到边缘的有符号距离 `sd`（内部为负）。
2. 只在距边缘 `refractionHeight` 以内做处理，更深处直接返回原像素。
3. 折射位移 `d = circleMap(1 − (−sd)/refractionHeight) × refractionAmount`，`circleMap(x) = 1 − sqrt(1−x²)`，边缘最弯、往里迅速衰减 —— 这正是凸透镜的剖面。
4. 位移方向取 SDF 梯度（指向法线），把采样坐标推出去，再 `content.eval()`。
5. 拆色版在 `d×grad` 上按 7 个色环各采一次再相加，边缘因此泛出彩虹。
6. 高光用同一套梯度与 45° 光向点乘，`pow(|d|, 1)` 得到只亮在两个对角方向的细边——这就是右上角那条白线的来源。

`refractionAmount` 是负值（向内推），符号写反会变成"膨胀果冻"。

## 六、降级矩阵

| 条件 | 表现 |
|---|---|
| API 33+ | 完整：折射 + 拆色 + 高光 |
| API 31~32 | 毛玻璃（`RenderEffect` 模糊 + 提饱和），无折射 |
| API < 31 | 纯色 `fallback` 板，不采背景 |
| 采样源未 attach | 退化为 `fallback` 纯色 |
| Web / CSS | `backdrop-filter` 模糊 + 内描边高光；按下时 `feDisplacementMap` 抖动近似折射，静止无折射 |

## 七、自检清单

对着真机截图逐条比：

- [ ] 药丸两端是完全半圆，没有直边段
- [ ] 指示器四周与药丸内壁的间隙恒为 5dp，上下左右一致
- [ ] 指示器压住的那一格，图标是实心、文字更粗，且**不会被模糊**
- [ ] 指示器边缘有白线，且只在上左 / 下右两个对角明显，不是整圈等亮
- [ ] 背后是深色封面时药丸偏暗，是亮色封面时偏亮（tint 是中性色，不要写死灰色）
- [ ] 快速甩动指示器会滑过一两格再停下，不是硬跳
- [ ] 按住指示器时它微微放大，且边缘出现彩边扭曲
- [ ] 拖到最左/最右仍有行程余量（橡皮筋），松手弹回

## 八、为什么这么设计

- **玻璃必须叠在内容之上、不能模糊内容**：所以是"先画玻璃再画内容"，而不是给内容加毛玻璃背景。这也是它和普通 `NavigationBar` 的根本差别。
- **两层玻璃而不是一层**：只有一层时，选中与未选中只是颜色差；叠第二层后，指示器有自己的折射与高光，才出现"液体在里面流动"的体积感。
- **手势自绘而不用 `clickable`**：`clickable` 无法表达"按住拖、松手带惯性、越界橡皮筋"这一整套连续状态，且会与页面横滑冲突。代价是要自己处理 `consume()` 与 `touchSlop`。
